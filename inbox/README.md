## 写作逻辑与事实边界

主线：看到一个结果 → 理解工作机制 → 理解价值 → 完成第一次使用 → 看个人案例 → 判断成本与限制。

- 产品能力以注明日期的官方资料为依据；价格、权益、版本在发表前再核对。
- 解释性框架与示例提示词属于写作建议，不写成官方术语或本人已跑通结果。
- 用户已确认名称为 Grok Bot；“Clock BOT”是前文误写。
- 用户已确认“流量代理”指把 Grok Bot 云电脑作为代理出口；它是云端电脑的一个个人扩展场景。具体软件、连接方式和效果仍待补。
- 日报、X 运营尚未提供真实产物和完整运行记录；不代写“已经自动发布”“稳定运行”或效率数据。
- 默认云端执行不等于所有操作只在云端；同账号多 Bot 共享云电脑，不是每 Bot 独享服务器。
- 当前模型由系统选择，不支持用户手动切换；Bot 邮箱与 Android 已有官方帮助说明。
