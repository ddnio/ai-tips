## 0. 钩子（30s）

**开口句**：「Grok Bot 是什么？一句话：给你配了一个能干活的 personal agent，还附赠一台高配云电脑。我用下来的真实感受，今天一次讲完。」

- 封面：Bot 在跑任务 + 云电脑配置同框（或各一张拼图）。

## 1. 什么是 Grok Bot（60s）

**开口句**：「先下定义。」

- 一句话定位：**personal agent**——不是聊天框，是能接活、跑任务的「员工」。
- 和普通 AI 对话的差别：能操作云电脑、能定时、能开多个 bot、能接入应用（只讲你见过的）。
- 账号本质：挂在 Cursor 账号体系下的 AI 工具附属（这一点第 3 章展开）。

## 2. 为什么要用（2min）

**开口句**：「四个优势，第四个最打动我。」

按 a–d 逐条讲，每条配一个你亲历的小例子：

1. **不只 AI，还带一台高配云电脑**｜截图：电脑配置页。举一个你真在云电脑上跑过的事。
2. **资料和操作在云端，多设备接力**：电脑端开的任务手机端能接着看/接着派（按实测说；手机端没用过就砍掉）。
3. **每个 bot 就是一个员工**：可以建群聊 bot、导入机器人、接应用、上定时任务——「团队」概念，不是单对话。
4. **迭代快**：bot 邮箱、模型切换等新功能（**没亲自验证的写「最近上线/待验证」，别当已核实卖点**）。

## 3. 怎么用（3min，含国内实测）

**开口句**：「怎么用我按国内的真实顺序讲：注册 → 下载 → 订阅 → 能不能裸连。」

### 3a. 注册登录 + 下载安装（约 1min）

- 本质先讲清：Grok Bot 本身「附属」在 Cursor 这类 AI 工具账号上，注册的是账号体系。
- 流程口述：手机号/邮箱注册 → 下载电脑端 → 用 Cursor 账号登录。
- 老用户一句提醒：旧的 500 次计划可能拿不到 Bot 权益，先切新用量计划（多人反馈，标注来源）。

### 3b. 如何订阅（约 1.5min，实测主干）

- 关键差异点：**国内能付**。截至 10/10 实测：关代理、无痕开 cursor.com/pricing → Pro 按月付 → 账单选 CNY → **支付宝扫码**。
- 价格口播一句：Pro 约 $20/月（以你的实付账单为准）；Ultra 差别放踩坑。
- 兜底句：「路径以实测为准，付款策略可能变；XPass 统一订阅有传闻，真上了我再补。」
- 截图见一页纸清单 5–9（打码）。

### 3c. 国内能不能裸连（约 30s，结论式）

- 一句话结论：「关掉代理，读 X / 生图 / 云电脑 / 联网搜索（按实测填）——几项通、几项不通。」
- 详细清单如果你要展开，就并进这里；想控制篇幅就一句话带过 + 评论区要清单，下一篇发实测长文。

## 4. 我的使用案例（2.5min）

**开口句**：「说三个我真在用的。」每个：目标 → 派给它什么 → 结果。

**顺序：X 运营 → 流量代理 → 日报**（X 运营放最前，受众重合；感兴趣的留下，后面才是你自己的场景）。

1. **X 运营**（放最前）：盯关键词 / 总结长帖 / 整理选题，挑真跑过的一两个说结果。
2. **流量代理**：口述注意措辞——说清你实际让它干的事（例：在云电脑里挂着监控/采集/路由类任务），**不碰「翻墙/代理服务」等合规敏感词**，按「云端任务」讲。
3. **日报**：定时任务怎么派、产出长什么样（这是「bot=员工」+定时的最好证据）。

> 案例不够三个就砍，只讲真跑过的；没结果的案例等于没有。

## 5. 踩坑（1.5min）

**开口句**：「坑在这，听完少走弯路。」按症状→解法：

1. **额度不太够**：你实测的消耗体感（例：x 轮任务掉了 y%），并给省额度建议（重活上云电脑前先小任务试）。
2. **一开「经此电脑转发流量」，Bot 打不开外网**：关这个开关（配截图）。
3. **订阅/权益不生效**：老用户先切新用量计划；付款页看不到支付宝 → 清缓存/换浏览器/换账号。
4. （可选）Pro vs Ultra：一句说清差在哪，别展开营销。

## 6. 附：最近功能更新清单（30s）

**开口句**：「最后甩个清单。」

- bot 邮箱、模型切换、（你观察到的其他）——每条一行，标注「已用过 / 待验证」。
- 收尾：「你在用 Grok Bot 吗？评论区说说你的用法，坑我也收。」
- 需要完整订阅步骤/裸连清单的，评论区要，热度够我发续篇。

## 口述注意事项

1. **先录 3b → 4 → 5**（订阅实测、案例、坑），这是全文骨架；1、2、6 后补。
2. 未核实卖点一律降级为「待验证」——尤其模型切换、多设备。
3. 时间锚点「截至 10/10 实测」；传闻加「传闻/未官宣」。
4. 「流量代理」全程换成「云端任务」类描述，不碰合规词。
5. 发后 24h 引用导流动作不变，见一页纸第 6 节。
