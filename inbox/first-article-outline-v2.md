## 0. 钩子（30s）

**开口句**：「不挂代理，支付宝扫码，当天就能让 Grok Bot 干活。我全走了一遍，今天把完整路径和踩到的坑一次讲完。」

- 只讲三件事：国内能用、能付钱、能派活。
- 不吹满血、不提 Opus。
- 封面图：关代理状态下 Bot 在跑任务的总览。

## 1. 这是什么、多少钱（60s）

**开口句**：「先花一分钟说清楚 Grok Bot 到底是个什么东西。」

- Grok Bot 是什么：装在电脑上的客户端，登录后能读 X、生图、联网搜、跑浏览器/云电脑任务（只讲你实测到的能力）。
- 账号从哪来：Cursor 账号体系，Pro 档大约 $20/月（按你实测的账单数字说）。
- Pro 和 Ultra 差在哪：额度/档位差异一句带过，细节放第 8 章坑里。
- **新增点**：这一章是原稿缺的，冷读者在这里决定要不要往下听。

## 2. 要准备什么（60s）

**开口句**：「你需要三样东西，都不难。」

- Cursor 账号（手机号或邮箱注册）——用来登录和计费。
- Grok Bot 电脑端——从下载页装好。
- 付款能力——支付宝即可，后面细讲。
- 每样一句话说清「是干什么的」，不展开教程。

## 3. 先用免费额度（30s）

**开口句**：「别急着付钱，注册完先白嫖。」

- 刚注册有免费额度；有人反馈 4 轮文字任务用掉 11%（注明来源是他人反馈）。
- 建议：先把第 7 章的任务用免费额度跑一遍，值不值再决定付。

## 4. 付钱：支付宝开 Pro（2.5min，核心）

**开口句**：「这一步是国内路径里最容易卡住的，我一步一步说。」

顺序口述（严格按实测顺序）：

1. 关掉 VPN/代理，用无痕窗口打开 cursor.com/pricing。
2. 选 Pro → 按月付。
3. 账单国家/币种选 **CNY**。
4. 支付方式列表里出现**支付宝**，扫码支付。
5. 到 dashboard/billing 确认已经是 Pro。

**实测边角料**（穿插讲，别堆成一段）：

- 看不到支付宝怎么办：清缓存 → 换浏览器 → 换账号（放第 8 章展开，这里只提一句「后面有坑」）。
- 账单截图注意打码订单号、个人信息。
- 一句话兜底：「截至 10/10 实测，路径是这样，付款策略可能变，发前我又走了一遍。」

## 5. 登录 + 切新用量计划（1.5min，核心）

**开口句**：「付完钱还不能直接用，登录这步有个老用户专属的坑。」

- Grok Bot 里选「用 Cursor 登录」。
- **老用户必须先切到新的用量计划**——旧的 500 次计划可能拿不到 Bot 权益（来源：realcoreychiu，1,239 曝光；你自己若复现过就写实测，没复现就标「多人反馈」）。
- 登录成功后去账户/套餐页确认权益，截图。

## 6. 裸连实测清单（2.5min，核心）

**开口句**：「接下来是这篇最值钱的部分：关掉代理，我逐项测了。」

**必须先出证据**：菜单栏/设置页显示代理已关。

逐项讲，每项一句结论 + 一句体感：

| 项 | 结论（按你实测填） |
|---|---|
| 读 X | |
| 生图 | |
| 云电脑 / 浏览器 | |
| Telegram 公共频道 | |
| 联网搜索 | |

- 能用的说能用，不能用的直说不能用，**「存疑」的写存疑**（学 xiangxiang103 的诚实写法）。
- 这一章决定收藏率，宁可结论平淡，不可夸大。

## 7. 第一天能派的活（2min）

**开口句**：「光能用没用，说几个我真派出去的任务。」

只写/只讲**你真跑过的**，每个任务：目标 → 派了什么 → 结果如何。候选（挑 5 个或更少）：

- 盯某个关键词的新帖
- 例程/定时小任务
- 一个 coding 小任务
- 浏览器跑腿（查点东西、填个表）
- 总结长帖

没跑过的别写进清单充数。

## 8. 常见坑（2min）

**开口句**：「坑我踩过的都在这，听完你能少走一小时弯路。」

按「症状 → 解法」讲：

1. 付款页看不到支付宝 → 清缓存 / 换浏览器 / 换账号。
2. 老用户权益没生效 → 先切新用量计划。
3. 一开「经此电脑转发流量」，Bot 就打不开外网 → 关掉这个开关（配设置页截图）。
4. 额度消耗比预期快 → 给出你实测的消耗体感。
5. Ultra 和 Pro 的区别 → 一句说清，不展开营销。

## 9. 收尾：XPass / 下一步（30s）

**开口句**：「最后两件事。」

- XPass 统一订阅传闻（X + Grok + Cursor + Bot，Plus 档 $30 价位传闻）一句带过：「真上了，付费路径可能变，到时我再补一篇。」
- 一句带过你打算接着试什么（可顺带一句：接微信那套看 KinGao 那篇，我不重复）。
- 行动号召：「卡在哪一步，评论区说，高频问题我补进常见坑。」

**原第 9 章「和 Claude / Codex 怎么搭」压成这里的半句**，不单独成章——不承诺模型档位，只说「不用单独买、没有封号焦虑」。
